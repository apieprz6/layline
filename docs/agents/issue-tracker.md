# Issue Tracker

Issues for this repo are tracked in **Linear**.

## Configuration

- **Workspace**: layline-sailing
- **Team**: layline
- **Issue format**: LAY-123

## How skills interact with Linear

Skills like `to-tickets`, `triage`, `to-spec`, `wayfinder`, and `code-review` use the **Linear MCP** to create and manage issues.

### Creating issues

Use the Linear MCP tools to create issues in the layline team within the layline-sailing workspace.

### Referencing issues

Always use the full issue identifier format: `LAY-123`

### Labels

See `triage-labels.md` for the canonical label vocabulary used by triage workflows.

## Manual workflow

If you need to create or manage issues manually outside of skills:
1. Use the Linear web UI at [linear.app/layline-sailing](https://linear.app/layline-sailing)
2. Or use the Linear MCP tools directly
3. Ensure issues are assigned to the "layline" team
